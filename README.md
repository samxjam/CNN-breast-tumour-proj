# Image-10
Repository for DATA3888 - Team Image 10
Note: "DL" refers to Double Layer, and "MC" refers to Multiclass

# !EXPLANATION OF GITHUB LAYOUT BELOW!

### "Image10_app" folder contains all code and models used in the app building process:
+ "demo" folder is the demo images used in the app
+ "models" folder are the .keras files the DL and MC models are saved in
+ "theme" folder contains the cerulean theme used in the app
+ all .py files are different draft apps produced
+ "final_app.py" is the final app used in presentation

### Other folders:
+ "basecodes" contains skeleton code for methods
+ "confidence_vals" contains prediction confidence values for both models
+ "history_vals" contains history values for both models
+ "workingcode" contains code we used along the modelling process (models we didn't use as final)

### "dlcnn_mixedsampling_models.ipynb" contains code used for final DL model:
- This was the code used to produce the plots used in the report for the DL model:
+ History plots for both accuracy and loss
+ Confusion matrix
+ Prediction confidence histogram

### "mccnn_mixedsampling_models.ipynb" contains code used for final MC model:
- This was the code used to produce the plots used in the report for the MC model:
+ History plots for both accuracy and loss
+ Confusion matrix
+ Prediction confidence histogram

### "DATA3888_Report.zip"
- Contains all source code to produce the report pdf
